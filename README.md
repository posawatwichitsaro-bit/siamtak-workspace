# Siamtak Workspace v2
Central Hub / Internal Application Launcher.

Run:
npm install
copy .env.example .env
npm start

Open http://localhost:3001

Demo:
admin/admin123
user/user123

The Hub presents subsystem cards, opens subsystem routes, opens Siamtak AI, and provides Admin system registry management.
The Admin icon field supports both direct emoji typing and selection from the icon picker.
