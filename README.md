Web app ที่เป็นจุดศูนย์กลางสำหรับการเข้าถึงระบบต่างๆ ที่ทำขึ้นเพื่อสนับสนุนงานต่างๆ ภายในองค์กร เช่น ระบบการดึงข้อมูลจากไฟล์ PDF, ระบบการตรวจสอบเอกสาร
โดยตัว Workspace จะรันอยู่บน Server ภายในองค์กร แล้วเครื่อง Client ที่อยู่ใน Network เดียวกันก็สามารถเข้าผ่าน Web Browser โดยเข้าผ่าน Port ที่เปิดไว้บน Server ได้
Siamtak Workspace เป็นจุดศูนย์กลางสำหรับระบบภายในที่พัฒนาขึ้นมาเพื่อสนับสนุนการทำงานของแต่ละแผนก หลังจากนี้ถ้ามีระบบอื่นที่ช่วยลดงานหรือเพิ่มประสิทธิภาพในแผนกอื่นก็สามารถพัฒนาและนำมา Integrate เข้า Workspace เดียวกันได้เรื่อย ๆ ตามแผนงาน
